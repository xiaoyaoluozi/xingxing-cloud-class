# 星星云课堂 - 能力评估系统 Demo

这是一个可交互的原型演示，用于展示星星云课堂儿童能力评估系统的核心功能。

## 🌐 在线访问

Demo 已部署在 GitHub Pages，可通过以下地址访问：

```
https://xiaoyaoluozi.github.io/xingxing-cloud-class/demo/
```

## ✨ 功能特性

### 1. 首页展示
- 项目介绍和评估说明
- 5 大评估维度展示
- 开始评估入口

### 2. 评估流程
- **引导页**：评估目的和流程说明
- **信息页**：填写孩子基本信息
- **测试页**：8 道精简题目（完整版的简化 Demo）
  - 家长观察题（家长根据日常观察作答）
  - 互动测试题（孩子直接在屏幕互动）
- **进度条**：实时显示答题进度

### 3. 结果报告
- **等级卡片**：L1/L2/L3 综合评级 + 星星图标
- **雷达图**：五维能力可视化展示
- **维度详情**：各维度得分 + 进度条
- **优势与关注**：智能分析强项和弱项
- **课程推荐**：根据评估结果推荐课程

### 4. 交互功能
- 题目切换（上一题/下一题）
- 答案选择（实时保存）
- 示例报告查看（快速体验）
- 分享功能（调用系统分享）
- 重新评估

## 🎨 设计特点

- **移动端优先**：响应式设计，适配手机/平板
- **温暖风格**：紫色渐变主题 + 星星黄色点缀
- **流畅动画**：页面切换、进度条、雷达图动画
- **无障碍设计**：清晰的视觉层次和交互反馈

## 🚀 使用方法

### 方法一：GitHub Pages（推荐）

1. 启用 GitHub Pages：
   - 访问 https://github.com/xiaoyaoluozi/xingxing-cloud-class/settings/pages
   - Source 选择 `Deploy from a branch`
   - Branch 选择 `main`，文件夹选择 `/docs`
   - 或者使用 `/demo` 分支

2. 访问地址：
   ```
   https://xiaoyaoluozi.github.io/xingxing-cloud-class/demo/index.html
   ```

### 方法二：本地运行

```bash
# 克隆仓库
git clone https://github.com/xiaoyaoluozi/xingxing-cloud-class.git
cd xingxing-cloud-class/demo

# 直接用浏览器打开
open index.html

# 或使用本地服务器
python3 -m http.server 8000
# 访问 http://localhost:8000
```

### 方法三：直接打开文件

直接双击 `index.html` 文件在浏览器中打开。

## 📊 Demo 数据说明

为简化演示，Demo 包含 8 道题目（完整版 32 题）：

| 题号 | 维度 | 类型 |
|------|------|------|
| 1 | 语言沟通 | 家长观察 |
| 2 | 语言沟通 | 家长观察 |
| 3 | 语言沟通 | 互动测试 |
| 4 | 社交情感 | 家长观察 |
| 5 | 社交情感 | 家长观察 |
| 6 | 视觉认知 | 互动测试 |
| 7 | 精细动作 | 家长观察 |
| 8 | 大运动 | 家长观察 |

**评分算法（简化版）：**
- ✅ 会 = 2 分
- ⚠️ 部分会 = 1 分
- ❌ 不会 = 0 分

**等级划分：**
- L1 基础启蒙级：≤40%
- L2 能力发展级：41-70%
- L3 社交融合级：≥71%
