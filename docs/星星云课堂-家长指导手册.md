## 第一部分：关于能力评估

### ❓ 为什么要做评估？

评估不是为了"贴标签"，而是为了：

| 目的 | 说明 |
|------|------|
| 🎯 了解孩子现状 | 清楚知道孩子在各方面的发展水平 |
| 📚 匹配适合课程 | 避免课程太难打击信心，或太简单没有挑战 |
| 📈 追踪进步轨迹 | 定期复评，看到孩子的成长变化 |
| 💡 发现优势短板 | 有针对性地强化薄弱环节 |

### ⚠️ 重要声明

**星星云课堂的评估不是临床诊断！**

- ✅ 这是**教育功能评估**，用于课程匹配
- ❌ 这**不能替代医院的专业诊断**
- 💡 如孩子尚未确诊，建议先到正规医院（儿童保健科/发育行为科）进行评估

## 第二部分：评估前准备

### 🕐 时间安排

| 项目 | 建议 |
|------|------|
| 最佳时间 | 孩子状态好的时段（通常是上午或午睡后） |
| 单次时长 | 15-20 分钟（可分 2-3 次完成） |
| 环境要求 | 安静、无干扰的空间 |
| 设备准备 | 手机/平板（确保电量充足、网络畅通） |

### 🧘 孩子状态准备

**适合评估的状态：**
- ✅ 孩子情绪稳定
- ✅ 刚吃过饭/零食，不饿不渴
- ✅ 没有困意
- ✅ 对新鲜事物有一定好奇心

**不建议评估的情况：**
- ❌ 孩子哭闹或情绪激动
- ❌ 生病或身体不适
- ❌ 刚经历环境变化（如搬家、换学校）
- ❌ 睡眠不足

### 🛠️ 物品准备清单

| 物品 | 用途 | 备注 |
|------|------|------|
| 手机/平板 | 进行测试 | 确保屏幕亮度适中 |
| 纸和笔 | 部分测试题需要 | 普通 A4 纸 + 粗头彩笔 |
| 儿童安全剪刀 | 精细动作测试 | 圆头安全款 |
| 小积木/珠子 | 部分观察题 | 家里已有的即可 |
| 小零食 | 奖励鼓励孩子 | 测试完成后给予 |

### 🎯 家长观察题 vs 互动测试题

#### 家长观察题（24 题）

这类题目需要您根据对孩子的了解来回答：

**示例题目：**
> Q1. 孩子能听懂并执行简单的一步指令（如"把杯子给我""坐下来"）

**如何作答：**
1. 仔细阅读题目描述
2. 回忆孩子最近一周的表现
3. 选择最符合的选项：
   - ✅ 会（经常能做到）
   - ⚠️ 部分会（偶尔能做到，或需要提示）
   - ❌ 不会（基本做不到）

**💡 小贴士：**
- 不要过度思考，凭第一感觉回答
- 不要拿孩子和别人比较，只和孩子自己比
- 如果不确定，可以选择"部分会"

#### 互动测试题（16 题）

这类题目需要孩子直接在屏幕上操作或您协助录制视频：

**示例题目：**
> Q4. 播放视频，视频中老师说"苹果"，请孩子跟读

**如何引导：**
1. 用轻松的语气说："我们来玩个游戏，跟着视频里的老师一起说"
2. 不要用"考试""测试"等给孩子压力的词
3. 如孩子不配合，可以暂停稍后再试
4. 每完成一题，给予即时鼓励（鼓掌/小贴纸）

**💡 小贴士：**
- 如孩子第一次不配合，可以隔 10-15 分钟再试
- 允许分天完成，系统会自动保存进度
- 如某题孩子完全拒绝，可跳过并记录原因

## 第五部分：在家配合学习

### 📺 视频学习建议

| 建议 | 说明 |
|------|------|
| **固定时间** | 每天固定时段学习，建立规律 |
| **短时多次** | 每次 10-15 分钟，比一次学很久更有效 |
| **家长陪伴** | 尤其是 L1 等级孩子，家长陪伴很重要 |
| **及时强化** | 孩子完成学习任务后，给予具体表扬 |

### 🎮 课后练习方法

**语言沟通课程后：**
- 在生活中泛化学到的词汇
- 创造使用机会（如"宝宝想喝水，怎么说？"）
- 多和孩子说话，即使孩子不回应

**精细动作课程后：**
- 提供类似材料让孩子自由探索
- 把练习融入日常生活（如扣纽扣、夹豆子）
- 不追求完美，重在参与

**社交情感课程后：**
- 角色扮演学到的社交场景
- 创造与同龄人互动的机会
- 及时指出孩子的社交进步

建议您记录孩子的学习情况，便于追踪进步：

## 第六部分：常见问题解答

### ❓ Q1: 孩子不配合测试怎么办？

**A:** 这很正常，很多孤独症孩子对新任务有抵触情绪。

**建议做法：**
1. 暂停测试，改天再试
2. 把测试包装成"游戏"而非"考试"
3. 先从孩子喜欢的互动题开始
4. 准备小奖励（贴纸/小零食）
5. 如多次尝试仍无法完成，可联系在线客服

### ❓ Q2: 评估结果准确吗？

**A:** 评估结果受多种因素影响：

| 影响因素 | 说明 |
|----------|------|
| 孩子当天状态 | 生病、疲倦会影响表现 |
| 环境干扰 | 嘈杂环境可能分散注意力 |
| 家长理解 | 题目理解偏差可能影响评分 |
| 孩子配合度 | 不配合会导致得分偏低 |

**建议：**
- 如认为结果不准确，可换个时间重新评估
- 复评结果通常更准确（孩子熟悉了流程）
- 评估结果是动态参考，不是一成不变的标签

### ❓ Q3: 多久复评一次？

**A:** 建议复评周期：

| 等级 | 建议复评周期 |
|------|--------------|
| L1 | 每 1-2 个月 |
| L2 | 每 2-3 个月 |
| L3 | 每 3-4 个月 |

**特殊情况需要复评：**
- 孩子刚完成一个课程阶段
- 孩子有明显进步或倒退
- 准备调整课程难度

### ❓ Q4: 评估结果会泄露隐私吗？

**A:** 不会。我们承诺：

- ✅ 评估数据仅用于课程推荐和进步追踪
- ✅ 数据加密存储，仅家长账号可查看
- ✅ 不会向第三方出售或共享数据
- ✅ 如需要删除数据，可联系客服处理

### ❓ Q5: 评估收费吗？

**A:** 星星云课堂是纯公益项目：

- ✅ 能力评估：免费
- ✅ 视频课程：免费
- ✅ 学习追踪：免费

本项目由蚂蚁志愿者团与星星学堂联合运营，所有服务均不收费。
