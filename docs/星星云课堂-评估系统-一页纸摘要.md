# 星星云课堂 - 儿童能力评估系统 一页纸摘要

**评审日期**：2026-10-25 | **版本**：V1.0 | **状态**：待评审

---

## 🎯 一句话概述

为 3-12 岁孤独症儿童设计的教育功能评估系统，通过 32 道互动题目评估 5 大能力维度，生成 L1/L2/L3 等级，精准匹配课程推荐。

---

## 📊 核心数据

| 指标 | 数值 |
|------|------|
| 题目数量 | 32 题核心 + 8 题备用 |
| 评估时长 | 15-20 分钟（可分次） |
| 评估维度 | 5 个（语言/社交/认知/精细/大运动） |
| 等级划分 | 3 级（L1/L2/L3） |
| 题目类型 | 家长观察 75% + 互动测试 25% |
| 复评周期 | 2-3 个月 |

---

## 🏗️ 系统框架

```
综合评级 (L1/L2/L3)
       │
   ┌───┴───┬───────┬───────┐
   ▼       ▼       ▼       ▼       ▼
 语言    社交    认知    精细    大运动
 25%     25%     20%     15%     15%
```

---

## 🎨 等级定义

| 等级 | 名称 | 得分率 | 课程匹配 |
|:----:|------|:------:|----------|
| L1 | 基础启蒙级 | ≤40% | 零门槛入门 |
| L2 | 能力发展级 | 41-70% | 需基础进阶 |
| L3 | 社交融合级 | ≥71% | 进阶挑战 |

---

## 📱 用户旅程

```
首页 → 评估入口 → 测试 (32 题) → 结果报告 → 推荐课程 → 学习
                                        │
                                        └→ 进步追踪 (复评)
```

**转化漏斗目标：**
- 评估渗透率 >50%
- 评估完成率 >80%
- 课程转化率 >70%

---

## 💡 核心亮点

| 亮点 | 说明 |
|------|------|
| ⚕️ **专业可信** | 参考 DSM-5、PEP-3、国家卫健委标准 |
| 💚 **家长友好** | 题目易懂，15-20 分钟完成，可分次 |
| 📈 **进步可视** | 雷达图 + 趋势图，清晰看到成长 |
| 🎯 **精准推荐** | 综合等级 + 维度得分 → 个性化课程 |
| 🔄 **可持续** | 定期复评，追踪长期进步 |
