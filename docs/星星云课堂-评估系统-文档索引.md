## 📋 评估系统核心信息

### 评估框架

```
                    ┌─────────────────┐
                    │   综合评级      │
                    │  L1/L2/L3      │
                    └────────┬────────┘
                             │
         ┌───────────────────┼───────────────────┐
         │                   │                   │
         ▼                   ▼                   ▼
   ┌──────────┐       ┌──────────┐       ┌──────────┐
   │ 语言沟通 │       │ 社交情感 │       │ 视觉认知 │
   │  (25%)   │       │  (25%)   │       │  (20%)   │
   └──────────┘       └──────────┘       └──────────┘
         │                   │                   │
         ▼                   ▼                   ▼
   ┌──────────┐       ┌──────────┐
   │ 精细动作 │       │ 大运动感统│
   │  (15%)   │       │  (15%)   │
   └──────────┘       └──────────┘
```

### 等级定义

| 等级 | 名称 | 含义 | 课程匹配 |
|------|------|------|----------|
| L1 | 基础启蒙级 | 需要较多支持 | 零门槛入门课程 |
| L2 | 能力发展级 | 需要中等支持 | 需基础进阶课程 |
| L3 | 社交融合级 | 需要较少支持 | 进阶挑战/亲子课程 |

### 题目设计

- **总题数**：32 题（核心）+ 8 题（备用）
- **题型**：家长观察题 (24 题) + 互动测试题 (16 题)
- **时长**：15-20 分钟（可分次完成）
- **评分**：✅ 会 (2 分) / ⚠️ 部分会 (1 分) / ❌ 不会 (0 分)
