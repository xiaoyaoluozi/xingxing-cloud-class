## 一、项目背景与目标

### 1.1 项目定位

**星星云课堂**是为 3-12 岁孤独症儿童打造的居家成长云课堂，由蚂蚁志愿者团 × 星星学堂联合发起。

| 核心数据 | 数值 |
|----------|------|
| 公益坚守 | 19 年 |
| 视频课件 | 2000+ |
| 受益儿童 | 3460+ |
| 服务人次 | 16.72 万 |

### 1.2 为什么需要评估系统？

**当前痛点：**

```
┌─────────────────────────────────────────────┐
│  😟 家长反馈                                │
│  • "视频太多，不知道从哪里开始"             │
│  • "孩子看不懂，学了没效果"                 │
│  • "学了一段时间，不知道有没有进步"         │
```

## 三、核心方案详解

### 3.1 测试题目设计

#### 题型分布

| 题型 | 题数 | 占比 | 说明 |
|------|------|------|------|
| 家长观察题 | 24 题 | 75% | 家长根据日常观察作答 |
| 互动测试题 | 16 题 | 25% | 孩子直接在屏幕互动 |

#### 题目示例

**家长观察题：**
```
Q1. 孩子能听懂并执行简单指令（如"把杯子给我"）

评分：
✅ (2 分) 能独立执行 3 种以上不同指令
⚠️ (1 分) 需要配合手势才能执行
❌ (0 分) 即使有手势提示也难以执行
```

**互动测试题：**
```
Q4. 跟读测试

[播放视频 10 秒] 视频中老师说"苹果"
请孩子跟读，录音提交

评分：
✅ (2 分) 能清晰模仿发音，相似度>70%
⚠️ (1 分) 有发音尝试，但相似度较低
❌ (0 分) 无反应或完全无法模仿
```

### 3.2 评分算法

```python
# 维度得分计算
维度得分 = 该维度题目得分之和 / 该维度满分 × 100%

# 综合得分计算（加权）
综合得分 = 语言×25% + 社交×25% + 认知×20% + 精细×15% + 大运动×15%

# 等级判定
if 综合得分 ≤ 40:
    return "L1"
elif 综合得分 ≤ 70:
    return "L2"
else:
    return "L3"
```

## 六、风险与应对

### 6.1 主要风险

| 风险 | 可能性 | 影响 | 应对措施 |
|------|--------|------|----------|
| 孩子不配合测试 | 高 | 中 | 提供跳过选项，允许复测 |

| 设备兼容性问题 | 中 | 中 | 测试主流机型 |
| 服务器性能不足 | 低 | 高 | 提前压测，准备扩容 |

### 6.2 应急预案

```
风险触发 → 监测告警 → 快速响应 → 问题解决
   │           │           │           │
   ▼           ▼           ▼           ▼
 定义阈值    自动通知    降级方案    根因分析
```

**具体预案：**
- 孩子不配合：允许跳过>5 题仍可生成报告（标注"仅供参考"）

## 九、Q&A

**常见问题预判：**

**Q1: 评估结果准确吗？**
> A: 评估基于权威标准设计，但受孩子状态、环境等影响。建议复评取趋势，而非单次结果。

**Q2: 评估会不会给孩子贴标签？**
> A: 不会。我们强调"能力发展"而非"缺陷"，报告用正向语言，强调进步和优势。

**Q3: 和医院评估有什么区别？**
> A: 我们是教育功能评估，用于课程匹配，**不是临床诊断**。建议未确诊孩子先到医院评估。

**Q4: 评估收费吗？**
> A: 完全免费。星星云课堂是纯公益项目。
